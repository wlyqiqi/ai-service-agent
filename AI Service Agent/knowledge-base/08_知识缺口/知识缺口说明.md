# 知识缺口说明

## 1. 文档目的与使用规则

本文档登记澄元智能家电当前**没有确定答案**的信息。

- 缺口未关闭前，任何文档（企业资料、产品资料、政策、客服语料、Agent 知识源）**不得暗中补充答案**。
- 涉及缺口的问询，统一口径为「该信息暂未公布 / 以官方通知为准」，不得推测、估算或承诺。
- 缺口关闭流程：业务方给出确定答案 → 更新对应权威文档（主数据 / 政策）→ 将本条移出本表并登记关闭日期。
- 缺口关闭若涉及规格或政策变更，须同步登记 `07_版本与变更/版本关系说明.md`。

## 3. 禁止暗中补充的规则

- 未登记答案前，不得在任意文档中为本表条目补写确定表述（数量、金额、时限、号码、承诺等）。
- 现有文档中已有的边界措辞（如「随市场开通」「以实际为准」「客服告知并更新预计时间」）属于流程描述，不构成答案，不得被引用为「已定义」。
- 若后续检查发现其他文档出现与本表冲突的确定表述，视为违规，须先提供权威依据或移回本表登记。

## 4. 与版本关系说明的衔接

- 缺口关闭后若产生规格或政策变更，按 `07_版本与变更/版本关系说明.md` 登记 supersedes 关系后，方可视为有效。
- 反向：版本登记中的任何新增规格，若源自缺口关闭，须在本表同步移除对应条目并留痕。

## 5. 检查与维护

- 本表随每次知识库审核复核：确认缺口未被暗中补充、已关闭条目有留痕。
- 新增缺口时编号顺延（GAP-011 ...），并注明发现日期与依据。
