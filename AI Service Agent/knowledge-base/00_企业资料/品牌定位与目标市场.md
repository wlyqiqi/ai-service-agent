# 品牌定位与目标市场

## 品牌定位

中高端智能家电品牌。价格与规格介于大众品牌与高端进口品牌之间，核心价值主张是「能力可预期」：宣称的功能在文档中有明确边界，App 能力与硬件能力一一对应。

## 目标市场

以下五个东南亚市场为正式销售区域：

| 市场 | 代码 | 说明 |
|---|---|---|
| 马来西亚 | MY | 主力市场之一，覆盖全产品线 |
| 新加坡 | SG | 城市家庭为主，全产品线 |
| 泰国 | TH | 全产品线 |
| 印度尼西亚 | ID | 全产品线 |
| 越南 | VN | 全产品线 |

所有在售产品均覆盖上述五国；单品的上市时间可能不同，以产品资料中的「当前产品状态」为准。

## 品牌调性

- 现代：界面与设计语言简洁，功能命名直观。
- 可靠：规格事实一致，限制条件透明。
- 温和：客服与文档语气平实，不施压。
- 克制：不使用夸张营销语言。
- 专业：技术参数结构化，避免模糊表述。

## 产品组合

- 厨房电器：JoyAir A1 / A1 Pro（空气炸锅）、JoyCook R1 / R1 Pro（电饭煲）、JoyBlend B1（破壁机）、JoyBrew C1（咖啡机）。
- 清洁电器：JoyClean V1（无线吸尘器）、JoyClean S1（扫地机器人）。
