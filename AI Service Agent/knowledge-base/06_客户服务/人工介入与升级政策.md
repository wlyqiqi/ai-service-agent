# 人工介入与升级政策

本文档定义全库「需人工介入 / 需审批」标记的统一口径。各政策文档中的此类标记均按本表执行。

## 升级层级

| 层级 | 角色 | 权限 |
|---|---|---|
| L1 | 客服代表 | 标准流程内处理；不得承诺政策外事项 |
| L2 | 主管 | 审批退款、补偿、特殊退货、政策例外（4 小时内） |
| L3 | 专项团队（安全/质控/法务） | 严重安全问题、大额争议、政策例外终审（安全事件 24 小时内响应） |

## 必须升级的场景（统一清单）

| 场景 | 升级要求 |
|---|---|
| 退款（超期/无凭证/大额 ≥ RM1,500 等值/补偿性） | L2 审批 |
| 补偿（超出政策范围） | L2 审批 |
| 特殊退货（超 7 天/无凭证/已使用争议/跨境） | L2 审批 |
| 严重安全问题（冒烟、起火、漏电、电池膨胀等） | 立即 L3 安全团队，24 小时内联系客户 |
| 政策例外（任何政策未覆盖或政策外要求） | L2 审批，不口头承诺 |
| 换新判定 / 维修超订单价值 50% / 停产替代方案 | L2 审批 |
| 账号异常 / 绑定争议 | L2 审批 |

## 安全事件流程（严重安全问题）

1. 立即停止使用并断电（客服指导客户操作）。
2. 登记事件信息（产品型号、SKU、购买时间、现象、照片）。
3. 24 小时内由 L3 安全团队联系客户。
4. 视情况安排返厂检测、换新或进一步评估；过程全程留痕。

## 审批纪律

- 所有审批记录（审批人、时间、理由、结果）留痕备查。
- 客服在任何审批结果出来之前，不得向客户承诺结果。
