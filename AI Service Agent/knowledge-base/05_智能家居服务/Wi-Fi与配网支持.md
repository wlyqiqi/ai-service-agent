# Wi-Fi 与配网支持

## 网络要求（与产品一致）

- 支持 Wi-Fi 的产品仅支持 **2.4 GHz** 频段，不支持 5 GHz。
- **JoyClean V1 无 Wi-Fi**：仅支持蓝牙查看电量与滤网寿命，不参与配网。
- 支持 Wi-Fi 的产品：JoyAir A1、JoyAir A1 Pro、JoyCook R1、JoyCook R1 Pro、JoyBlend B1、JoyBrew C1、JoyClean S1。
- JoyClean S1 的配网与地图功能必须使用 2.4 GHz Wi-Fi。

## 配网方式

- 标准配网：Chengyuan Home App 内按引导连接。
- 蓝牙辅助配对：JoyAir A1 Pro、JoyCook R1 Pro、JoyBrew C1、JoyClean S1 支持蓝牙 5.0 辅助初始配对；JoyClean V1 仅蓝牙状态查看。

## 常见问题

- 路由器为双频合一：需在路由器设置中拆分或使用 2.4 GHz 专属 SSID。
- 设备搜索不到：确认设备处于配网模式、手机与设备在同一网络。
- 信号弱/频繁掉线：缩短设备与路由器距离，避免金属遮挡。
- 更换路由器后：需在 App 中重新配网。

## 服务边界

- 涉及运营商网络、企业/校园认证网络的连接问题，客服可提供常规排查建议，但不承诺解决。
- 公网中断不影响设备本地基本操作；远程控制与地图同步依赖网络。

## 需人工介入或审批的场景

- 常规排查无效的兼容性问题：客服记录并升级 L2。
- 企业网络/认证网络导致的无法配网：如实说明限制，不承诺绕过方案。
