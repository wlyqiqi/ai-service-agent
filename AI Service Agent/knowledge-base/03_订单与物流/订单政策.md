# 订单政策

## 适用范围

本政策适用于通过澄元官方线上渠道（官网与授权电商渠道）购买 Chengyuan Smart Home 全部产品的订单。覆盖市场：马来西亚、新加坡、泰国、印度尼西亚、越南。

## 订单流程

下单 → 支付 → 订单确认 → 发货 → 签收 → 完成。

- 支付成功且系统确认后，订单进入「待发货」状态。
- 支付成功但系统未确认（异常订单），由客服人工核查，不自动取消。

## 订单状态定义

| 状态 | 含义 |
|---|---|
| 待支付 | 已下单未完成支付 |
| 待发货 | 已支付，等待发出 |
| 已发货 | 包裹已交承运商 |
| 已完成 | 客户确认签收或超过签收确认期 |
| 已取消 | 按取消订单政策处理 |

## 订单修改

- 订单处于「待发货」时可修改收货地址，规则见 `03_订单与物流/修改地址政策.md`。
- 已发货订单不可修改商品与地址；如需变更，按取消订单与退换货政策处理。
- 每笔订单限修改地址 1 次。

## 账号与订单

- 建议使用 Chengyuan Home App 账号下单：订单记录、发票与保修查询均与该账号关联。
- 未登录下单（游客订单）亦可保修，但需提供订单号或发票作为凭证。

## 需人工介入或审批的场景

- 支付成功但订单未确认（异常订单）：客服人工核查。
- 订单信息与支付记录不符、疑似盗刷：立即升级 L2，必要时冻结订单。
