# 退换货政策

## 无理由退货

- 自签收之日起 **7 天内**，商品保持不影响二次销售状态，可申请无理由退货。
- 影响二次销售的情形包括但不限于：包装严重破损、配件缺失、商品已使用或已清洗、防拆贴被移除。

## 质量问题（保修内）

- 保修期内（整机 12 个月）出现的非人为质量问题，按 `04_售后服务/保修政策.md` 处理（维修/换新），不强制要求 7 天内申请。
- 质量问题导致的寄回运费由品牌承担。

## 退货流程

1. App 或客服渠道提交退货申请。
2. 审核通过后获得退货单号与退货地址。
3. 寄回商品（完整包装、配件、赠品）。
4. 仓库验收（1–3 个工作日）。
5. 验收通过后发起退款（见退款政策）；换货则安排补发。

## 运费承担

- 无理由退货：寄回运费由客户承担。
- 质量问题/品牌责任：寄回运费由品牌承担（客户垫付后凭单据报销，或以到付寄回）。

## 特殊退货（需人工介入或审批）

| 情形 | 处理 |
|---|---|
| 超过 7 天无理由窗口 | 不受理无理由退货；引导保修或收费维修。仅当存在未登记的质量问题时，由 L2 审批特例 |
| 无原始凭证退货 | 需 L2 审批，验证购买记录后受理 |
| 已使用商品的质量争议 | L2 会同质控判定，必要时返厂检测 |
| 跨境退货（跨市场） | 特殊流程，L2 审批；运费与税务以实际发生为准 |
| 大额订单退货（≥ RM1,500 等值） | 退款按退款政策大额标准，需 L2 审批 |

## 禁止事项

- 未经审核直接寄回的商品可能被退回客户，运费客户自理。
- 客服不得承诺政策外退货条件。
