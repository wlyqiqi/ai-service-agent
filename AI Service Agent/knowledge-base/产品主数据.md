## 4. JoyAir A1 智能空气炸锅（权威规格）

- 型号：JoyAir A1；SKU：CY-AF-A1-45；定位：入门级智能空气炸锅，面向 3–4 人家庭。
- 容量：炸篮 4.5L；额定功率 1500 W；温度范围 80–200°C；定时范围 1–60 分钟；加热方式：顶部 360° 热风循环。
- 预设程序：8 个（薯条/鸡翅/烤鱼/蛋糕/解冻/烘烤/风干/保温）。
- 尺寸：约 320×300×340 mm（宽×深×高）；重量：约 4.8 kg。
- 配件：炸篮（BA-A1-45）、烤架（GR-A1-45）、烘焙纸试用装（PP-A1-05）。
- App（基础）：远程启停、定时、温度设置、基础食谱（约 60 道）；无自定义曲线、无固件 OTA。
- Wi-Fi：支持 2.4 GHz；蓝牙：无。
- 限制：最低温度 80°C；不支持旋转烤叉/转笼；无可视窗；A1 与 A1 Pro 的炸篮、烤架不通用。
- 错误代码：E1 温度传感器异常；E2 加热元件异常；E3 风扇电机异常；E4 主控通信异常。
- 保养要点：炸篮/烤架冷却后可水洗；机身湿布擦拭；每 1–2 周清洁进/出风口。
- 状态：active（在售），2025-10 上市，覆盖全 5 国。

## 13. SKU / 型号命名规则

- SKU 前缀：`CY-`（品牌）+ 品类码（AF=空气炸锅 / RC=电饭煲 / BL=破壁机 / CM=咖啡机 / VC=吸尘器 / RV=扫地机器人）+ 系列码 + 容量/序号。
- 例：`CY-AF-A1-45` = 空气炸锅 A1 系列 4.5L；`CY-RV-S1-00` = 扫地机器人 S1（无容量差异项以 00 结尾）。
- 配件型号独立编号；通用配件以 `COMMON` 结尾。
